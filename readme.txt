# Tinkercad Home Automation

## Components
- Arduino UNO
- Photoresistor
- PIR sensor
- LED
- Servo motor
- 16x2 LCD

## Working
The photoresistor detects light and the PIR sensor detects motion.
Arduino processes the sensor signals and controls the LED and servo motor.
The LCD displays the system status.

## Simulation
This project was designed and tested using Tinkercad Circuits.
